# تمرین ۴: شبیه‌سازی دوم (ارسال‌یار)

⏱️ **دقیقاً ۲ ساعت.** با تایمر.

تازه به تیم پنل فروشندگان «ارسال‌یار» اضافه شدی. ۱۵ تیکت باز تو `TICKETS.md` هست. **قرار نیست همه‌ش تموم بشه.**

## اجرا
```bash
npm install
npm run dev
```
React Query Devtools نصبه (گوشه‌ی پایین-چپ).

## درباره‌ی پروژه
- سه صفحه: لیست مرسوله‌ها (`/`)، جزئیات (`/shipments/:id`)، ثبت مرسوله‌ی جدید (`/new`)
- React Query (شامل `useInfiniteQuery`)، axios، React Hook Form و Zod
- **API:** `mock-api.ts` بک‌اند تیم دیگه‌ست: **تغییرش نده.**
  - وضعیت‌ها: `PENDING`، `IN_TRANSIT`، `DELIVERED`، `CANCELLED`
  - **همه‌ی مبالغ به ریال‌ان.**
  - مرسوله‌ی تحویل‌شده یا لغوشده رو نمی‌شه لغو کرد (سرور `409` برمی‌گردونه).

## قوانین
- AI مجازه؛ هر خطش رو باید بتونی توضیح بدی.
- برای هر تیکت: **بازتولید ← علت ← فیکس ← دوباره انجام دادن مراحل تیکت.**

## این بار، این‌ها رو حتماً رعایت کن
1. **۱۰ دقیقه‌ی اول کد ننویس.** تیکت‌ها رو مثل کارآگاه بخون و برای هر کدوم یه فرضیه‌ی یک‌خطی بنویس.
2. **اولویت‌بندی با دلیل.** پول و داده اول؛ بعد چیزهایی که جلوی کار اصلی رو می‌گیرن.
3. **بعد از هر فیکس، مراحل همون تیکت رو دوباره انجام بده.** تا ندیدی درست شده، نرو سراغ بعدی.
4. **ریشه، نه علامت.** اگه یه باگ چند جا خودش رو نشون می‌ده، دنبال جایی بگرد که دیتای غلط وارد می‌شه.
5. **قبل از تحویل `npm run typecheck`.** و فایل نصفه‌کاره‌ی اضافه نذار.
6. **۱۰ دقیقه‌ی آخر فقط `REPORT.md`،** با شماره‌ی دقیق تیکت‌ها (ERS-2xx).
