# تمرین دیباگ ۱: صفحه‌ی مقایسه‌ی بیمه

⏱️ زمان: ۲۰ دقیقه

## اجرا
```bash
npm install
npm run dev
```

## گزارش باگ‌ها (از طرف تیم محصول)

1. **«وقتی نوع بیمه رو از شخص ثالث به بدنه عوض می‌کنم، لیست عوض نمی‌شه.»**
2. **«دکمه‌ی مرتب‌سازی بر اساس قیمت کار نمی‌کنه.»**
3. **«تیک مقایسه رو روی بیمه‌ی ایران زدم، بعد بیمه‌ی ایران رو حذف کردم. حالا تیک روی یه بیمه‌ی دیگه افتاده!»**

## قوانین
- برای هر باگ: اول **بازتولیدش کن**، بعد **علت** رو پیدا کن، بعد درستش کن.
- علت هر باگ رو با یه جمله به زبان خودت بنویس. توضیح، به اندازه‌ی خود فیکس مهمه.
- بلند فکر کن، انگار یه مصاحبه‌گر کنارت نشسته.
- اگه وقت اضافه داشتی: یه چیز دیگه هم تو این کد هست که تو یه code review واقعی بهش ایراد می‌گرفتی. پیداش کن.
